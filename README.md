Репозиторий: [Kibosh13/forma-201](https://github.com/Kibosh13/forma-201). Демонстрация: [GitHub Pages](https://kibosh13.github.io/forma-201/).

Исходники находятся в `main`, готовая демонстрация — в `gh-pages`. Инструкции по публикации, обновлениям и отключённым функциям: [PUBLICATION.md](PUBLICATION.md).

Перед публикацией удалены сохранённые идентификаторы сессий Битрикса. `.env`, базы данных, зависимости, логи, сборки и резервные необработанные дубликаты исключены из Git. Упоминаемые ниже `original-text/` и журналы/отчёты проверки остаются только в исходной локальной рабочей папке и не входят в репозиторий.

## Исходный локальный снимок

Снимок публичной части сайта от 8 сентября 2026 года. Фотографии скачаны без редактирования: существующие водяные знаки сохранены.

## Открыть сайт

Если локальный сервер уже запущен: **http://127.0.0.1:8847/**.

Для повторного запуска откройте `start.command` двойным щелчком либо выполните в этой папке:

```sh
python3 serve.py
```

Затем откройте указанный адрес в браузере. Для остановки нажмите Ctrl+C в окне сервера. Нужен Python 3.9 или новее; сторонние библиотеки для просмотра не нужны. Если порт занят, можно выбрать другой: `python3 serve.py --port 8848`.

Открывать HTML напрямую через `file://` не следует: исходный сайт использует пути от корня, а карточки имеют расширения `.prod` и `.tag`. Встроенный сервер сохраняет правильные адреса, типы содержимого, перенаправления и страницы пагинации.

## Где лежат файлы

Корень сайта — **`site/`**. Путь после имени домена соответствует пути внутри этой папки:

| Адрес на исходном сайте | Локальный файл |
| --- | --- |
| `/` | `site/index.html` |
| `/catalog/` | `site/catalog/index.html` |
| `/catalog/alyuminievaya-dvernaya-korobka-l.prod` | `site/catalog/alyuminievaya-dvernaya-korobka-l.prod` |
| `/upload/iblock/.../photo.jpg` | `site/upload/iblock/.../photo.jpg` |
| `/upload/medialibrary/.../photo.jpg` | `site/upload/medialibrary/.../photo.jpg` |
| `/upload/resize_cache/.../photo.jpg` | `site/upload/resize_cache/.../photo.jpg` |
| `/local/templates/...` | `site/local/templates/...` |
| `/bitrix/cache/...` | `site/bitrix/cache/...` |

Фотографии и другие файлы не переименовывались. В папках страниц добавлен обычный `index.html`. Параметры версий у статических ресурсов обслуживаются тем же файлом. Страницы с `?PAGEN_…` хранятся отдельно в `site/_mirror/query/`; сервер сопоставляет их исходным адресам. Ресурсы сторонних CDN сохранены в `site/_external/<домен>/…`.

## Работа с фотографиями

- `metadata/images.json` — полный список изображений, их размеры в байтах, контрольные суммы и соответствия миниатюр полноразмерным файлам, когда исходник доступен.
- `metadata/products.json` — адреса, заголовки, файлы карточек и пути изображений на каждой карточке. Список изображений страницы также включает элементы общего оформления.
- Для замены изображения с сохранением ссылок сохраните новую версию под тем же именем и по тому же пути в `site/`.
- **Миниатюры в `resize_cache` — самостоятельные файлы.** Замена полноразмерного фото в этой статической копии сама по себе не обновляет миниатюры. Автоматическое создание вариантов и нанесение нового водяного знака пока не реализованы.

## Изменения для локального просмотра

Абсолютные ссылки на страницы и файлы `dial-td.ru` в рабочей вёрстке переведены на локальные пути. Подключённые статические CDN-ресурсы также заменены локальными адресами. Содержимое фотографий не менялось.

`original-text/` содержит точные исходные версии текстовых файлов, затронутых локализацией. Остальные исходные файлы совпадают с рабочими. Исходные XML-карты сайта и `robots.txt` сохранены с прежним доменом; перед будущей публикацией их потребуется настроить заново.

## Проверки и исключения

- Проверены контрольные суммы всех скачанных файлов и целостность растровых изображений: ошибок нет.
- Все **3 078 скачанных адресов** проверены через локальный HTTP-сервер: ошибок нет. Для главной, карточки товара, страницы подборки, пагинации, фотографии, CSS и PDF также сверено выдаваемое содержимое.
- Проверены ссылки HTML и CSS. Недоступные зависимости перечислены в `metadata/verification.json`; они отсутствуют уже на исходном сервере.
- Фотографии товаров скачаны; отсутствующие изображения относятся к файлам оформления и служебным ссылкам в шаблоне.
- Два недоступных адреса из исходной карты сайта: `/catalog/alyuminievyy-dvutavr/` и `/catalog/alyuminievyy-tavr/`. Актуальные доступные разделы под `/catalog/stroitelnyy-alyuminievyy-profil/` сохранены.
- Один исходный MP4-файл возвращает 404: `/upload/medialibrary/292/rio8p3pulpoygfnuwa96cp4ro60v5mv0.mp4`.

Подробности: `metadata/manifest.json` (адрес → файл и результат скачивания), `metadata/verification.json` (полнота и целостность), `metadata/http-verification.json` (локальная выдача), `metadata/download-log.jsonl` (журнал).

Проверки выполнены по файлам, ссылкам и HTTP-ответам; визуальное совпадение каждого экрана и работа всех интерактивных элементов в браузере не проверялись.

## Граница этой копии

Это **статическая копия доступной публичной части**, а не резервная копия установки «1С-Битрикс». Папки `bitrix/` и `local/` содержат публичные скрипты, стили и шаблонные ресурсы, а не восстановленную CMS.

Серверный PHP-код, база данных, админка, скрытые файлы, обработчики форм, поиск, произвольная серверная фильтрация и другие функции CMS снаружи недоступны и не восстановлены. Они потребуют отдельной реализации либо доступа к резервной копии/хостингу.

Локальный сервер запрещает фоновые обращения страницы к внешним сервисам. Поэтому аналитика, онлайн-чат, внешние карты и встроенные Rutube/YouTube/Vimeo-видео офлайн не работают. Формы не отправляют заявки; POST-запрос получает понятный ответ о статической копии. Обычные внешние ссылки, телефон и электронная почта сохранены.

Доступность проверена по опубликованным картам сайта, внутренним ссылкам, ссылкам на ресурсы и доступным оригиналам миниатюр. Неопубликованные файлы и страницы, на которые нет обнаруживаемых ссылок, нельзя перечислить без доступа к серверу.
