# Боевая версия alymprofi.ru

Боевая версия работает на WordPress и WooCommerce. Статическая GitHub Pages-версия остаётся отдельным архивом и не используется как CMS.

## Что редактируется в админке

- **Товары**: название, цена, единица цены, статус «В наличии / Под заказ», описание, характеристики, категории и изображения.
- **Товары → Категории**: создание, редактирование, удаление, иерархия, описания и изображения категорий.
- **Страницы**: обычные тексты сайта.
- **SEO**: заголовок и описание Yoast SEO у страниц, товаров и категорий.
- **Настройки сайта**: логотип, изображение первого экрана, название компании, телефон, email, адрес, режим работы и главные тексты.
- **Внешний вид → Меню**: главное меню и ссылки в подвале.

Изображения выбираются из медиатеки или загружаются с компьютера. Ручные пути к файлам не нужны.

## Исходники интеграции

- `wordpress/alymprofi-theme/` — тема боевого сайта.
- `wordpress/alymprofi-core/` — поля админки и команда импорта.
- `tools/export_wordpress_catalog.py` — преобразование сохранённого каталога в JSON для WooCommerce.

Сгенерированный `.wordpress-build/catalog.json` не коммитится.

## Обновление каталога из архива

```sh
PYTHONPATH=/path/to/beautifulsoup4 python3 tools/export_wordpress_catalog.py
wp alym import /path/to/catalog.json --images=0
```

После первичного импорта содержимое следует редактировать в WordPress. Повторный полный импорт обновляет товары из архивных HTML и может перезаписать изменения редактора.
